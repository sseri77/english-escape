기본 3개 배우기 → 읽기·암기 → 기본 문제 → 응용 2개 → 5개 숙달.

1. 먼저 세 단어를 배워요

이렇게 읽는 이유

한글 읽기 표기는 보조 힌트예요. 실제 영어 소리는 모범 발음으로 함께 익혀요.

2. 세 단어 읽기·암기 연습

단어를 혼자 읽고, 읽는 법과 뜻을 확인해주세요. 세 단어를 모두 연습하면 기본 문제로 넘어갑니다.

그림과 설명 다시 보기 · 녹음 연습

🎤 내 발음 확인 · 녹음으로 비교

모범 발음을 듣고 직접 읽어보세요. 이 버전은 자동 채점 대신 내 녹음과 비교하는 연습을 제공합니다.

녹음은 기기에만 머물며, 단어를 바꾸거나 화면을 닫으면 삭제됩니다.

3. 배운 세 단어 확인

세 단어를 모두 맞혀보세요. 틀리면 설명을 보고 같은 단어에 다시 도전합니다.

4. 처음 보는 응용문제 두 개

방금 배운 읽기 규칙을 새로운 단어에 적용해보세요. 두 문제를 맞히면 총 다섯 단어로 숙달 훈련을 시작합니다.

5. 다섯 단어 모두 익히기

각 단어를 10회 연속 맞히면 통과해요. 다섯 개를 모두 통과하면 다음 단계가 자동으로 시작됩니다.

2단계부터는 훈련 묶음마다 이전 단계에서 배운 문제 1~2개가 랜덤으로 섞여요. 모든 객관식 보기도 매번 섞습니다.

기억을 단단하게

읽는 법과 뜻을 함께 익혀요.

읽는 법·뜻·소리를 번갈아 확인해요. 틀린 단어는 다시 연습하고, 다른 단어의 기록은 유지됩니다.

발음 녹음은 퀴즈 점수에 포함되지 않아요. 듣기 문제에서만 제출 전에 음성을 들을 수 있어요.
