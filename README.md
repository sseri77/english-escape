# 왕초보 영어 탈출기

**현재 사용하는 버전은 `/docs` 안의 GitHub Pages 웹앱입니다.**
Python 서버나 카페24 없이 브라우저에서 실행합니다.

## 제공 기능
- 1~50단계: 파닉스 규칙과 생활 단어 250개 (기본 150 + 응용 100).
- 51~60단계: 짧은 문장 50개 (기본 30 + 응용 20). 원하는 단계에서 자유롭게 시작.
- 한 화면에서 기본 3개와 설명·발음 듣기 → 기본 3문제 → 응용 2문제 → 5개 숙달 → 새 단어 2개 확인의 안내형 수업.
- 수업 순서를 저장하고 미완료 구간을 건너뛰지 않음.
- 응용문제 다음에 기본 3개 + 응용 2개의 반복 퀴즈로 바로 이어짐. 모두 5회 연속 맞힌 뒤 별도로 준비한 새 단어 2개를 확인하면 다음 단계 자동 시작. 51단계부터는 새로운 문장으로 확인.
- 2단계부터 이전에 학습한 문제 1~2개를 매 훈련 묶음에 섞음. 복습 오답은 현재 수업을 되돌리지 않음.
- 객관식 보기에는 Fisher-Yates 셔플 적용: 수업·응용·숙달·복습·재도전마다 다시 섞음. 랜덤이므로 우연히 같은 순서가 나올 수 있음.
- 한글 보조 읽기 힌트와 글자 소리 연결, CAP/CAPE 등 비교 예시.
- 기본·응용 단어 및 문장 300개에 소리 나누기·이어 읽기·묵음 및 예외 설명. 단어 카드·단어장·퀴즈 설명·기본/응용 피드백에서 확인.
- 읽는 법 고르기, 뜻 고르기, 듣기, 영어 연결의 반복 퀴즈.
- 한글 읽기 힌트는 영어 음성과 완전히 같지 않으므로 모범 발음과 함께 학습.
- 항목별 5회 연속 정답 통과. 오답은 해당 항목만 0으로 초기화. 이전 10회 기준의 학습 기록은 5회 기준으로 이어받음.
- 5회 통과 후 1·3·7·14·30일 간격 복습. 단계가 끝날 때까지 반복되는 정답은 복습 예약을 앞당기지 않음. 통과는 영구 암기 보증이 아님.
- 별도 복습 메뉴 없이 수업 시작 전 날짜가 된 완료 단계 항목을 최대 5개 복습. 오답과 힌트 사용 문제는 다시 출제하고, 성공 시 다음 간격을 예약한 뒤 원래 수업으로 복귀.
- 읽기 문제는 영어를 먼저 제시하고 ‘보기 열기’를 눌러 선택. 한글 힌트·정답 음성·설명을 먼저 열면 연속 정답/새 단어 통과에 포함하지 않음. 듣기 문제 및 p/f 소리 선택용 음성은 문제의 일부이므로 제외.
- 단계마다 사전 노출하지 않는 새 단어/문장 확인 2개(총 120개). 객관식 읽기 규칙 적용 확인이며 실제 목소리나 발음 정확도를 자동 채점하지 않음. 재도전한 문항은 이전 피드백을 통해 이미 접한 문항임.
- 초기 과정에 p/f, e/i 소리 비교와 짧은 구절 듣기를 추가. 구절의 a 발음과 뜻을 별도로 안내.
- 기존 완료 단계와 풀이 기록 유지. 진행 중인 단계에는 새 단어 확인 절차를 적용.
- 영어/한국어 검색, 학습 상태 필터, 한 번에 30개씩 펼치는 단어장, 통계, 단어별 재시작/기록 삭제.
- 전체 진도 초기화와 전체 기록 삭제 구분. 삭제 전 확인.
- 기록 JSON 백업/복원. 브라우저 localStorage 자동 저장.
- 단어별 발음 듣기/천천히 듣기. 별도 선택 연습·녹음 영역 없이 단어 카드에서 바로 재생.
- 글자 크기 18/20/22px, 밝은/어두운 화면, 기기 테마 따르기.
- 홈 화면용 PNG 아이콘, PWA manifest, 최초 방문 후 오프라인 학습 캐시.
- 앱을 연 상태의 학습 시간 안내, 캘린더 일정 파일 내보내기.

## GitHub Pages 켜기
1. 저장소 Settings → Pages.
2. Build and deployment → Source: **Deploy from a branch**.
3. Branch: **main**, 폴더: **/docs**, Save.
4. Pages 화면의 배포 완료 안내에서 실제 주소 확인.

예상 주소: https://sseri77.github.io/english-escape/
이 주소는 Pages 활성화와 배포 성공 전에는 사용할 수 없습니다.

GitHub Free는 Public 저장소에서 Pages를 제공합니다. Private 저장소는
Pro 등 지원 플랜이 필요합니다. 현재 저장소 공개 범위는 앱에서 변경하지 않습니다.
설정에 플랜 업그레이드 안내가 나오면 본인이 공개 여부를 결정해야 합니다.
사이트가 공개되면 웹앱 소스와 교재는 방문자가 볼 수 있습니다.
학습 기록·녹음·백업 파일은 저장소에 업로드하지 않습니다.

## 아이폰 사용
Safari로 배포 주소 열기 → 공유 → 홈 화면에 추가.
녹음은 HTTPS와 마이크 허용이 필요합니다. 소리는 현재 기기 출력으로 재생됩니다.
영어 음성이 없거나 네트워크 음성이 오프라인이면 듣기가 작동하지 않을 수 있습니다.

## GitHub만 사용하는 범위
구글 계정 로그인/기기 간 자동 동기화/앱을 닫은 동안 예약 푸시/정밀 발음 자동 평가는
제공하지 않습니다. 녹음은 모범 발음과 직접 비교하며 채점 결과를 만들어내지 않습니다.
음성은 외부 평가 서버로 전송하지 않습니다. 기기 자체 TTS는 OS 음성 설정에 따릅니다.
진도는 기기·브라우저별입니다. 데이터 삭제/비공개 모드/기기 변경 전 백업하세요.

## 로컬 확인
```sh
python -m http.server 8080 --directory docs
node --test tests/static.test.cjs
```
http://localhost:8080 열기. Python은 이 미리보기나 교재 생성에만 쓰이며 Pages에선 실행하지 않습니다.
`tools/build_curriculum.py`는 원본 교재 데이터를 `docs/assets/curriculum.js`로 만듭니다.

## 이전 Python 실험본
루트 app.py, pronunciation.py, templates/, static/ 등은 이전 서버 방식 실험본입니다.
GitHub Pages에는 `/docs`만 게시하므로 서버 파일과 .env.example은 배포되지 않습니다.
현재 실행 방법은 이 문서가 기준입니다. Azure API 키는 필요하지 않습니다.

교재 읽기 힌트 생성: `python tools/build_reading.py`.

응용 항목 생성: `python tools/build_applications.py` · 자동 검사: `npm install && npm test`.
